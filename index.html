DrawPDF 개인정보처리방침

시행일자: 2026년 9월 1일 | 최종 수정일자: 2026년 9월 7일

DrawPDF(이하 "앱")는 사용자의 개인정보를 매우 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 본 방침은 앱이 사용자의 정보를 어떻게 처리하고 보호하는지 설명합니다.

1. 수집하는 개인정보 항목 및 수집 방법

앱은 원칙적으로 사용자를 식별할 수 있는 고유한 개인정보(이름, 주민번호, 전화번호, 이메일 계정 등)를 수집하거나 서버에 저장하지 않습니다.

  • 문서 및 필기 데이터: 사용자가 불러오거나 작성한 PDF 문서, 펜 필기, 주석 등은 사용자의 기기 로컬 저장소에만 저장됩니다.
  • 음성 녹음 데이터: AI 회의록 작성 시 녹음된 음성 데이터는 사용자의 기기에 로컬 파일로 저장되며, 전사(STT) 및 요약 요청 시에만 API로 암호화 전송됩니다.

2. 접근 권한 안내

앱은 원활한 기능 제공을 위해 다음의 기기 권한을 필요 시에 한하여 요청합니다.

  • 저장공간 / 사진 / 파일 접근 권한: PDF 문서 열기, 저장, 이미지 주석 첨부, 문서 내보내기 목적
  • 마이크(오디오 녹음) 권한: 음성 녹음 및 AI 회의록 분석 기능 사용 목적
  • 카메라 권한: 문서 내 직접 촬영한 사진 주석 첨부 목적
  • 네트워크(인터넷) 권한: AI 회의록 생성(Gemini API 통신) 및 기기간 실시간 화면 공유 목적

3. 제3자 제공 및 위탁

앱은 사용자의 개인정보를 외부에 제공하지 않습니다. 단, AI 회의록 요약 기능 사용 시 사용자가 동의한 경우에 한하여 아래의 서비스로 암호화 통신을 수행합니다.

  • 제공받는 자: Google LLC (Google AI Studio / Gemini API)
  • 제공 항목: 회의 음성/텍스트 데이터
  • 이용 목적: 음성 전사 및 회의록 요약 텍스트 생성

4. 개인정보의 보유 및 파기

앱에서 생성된 모든 데이터는 사용자 기기에 로컬로 보관되며, 사용자가 앱 내에서 삭제하거나 앱을 삭제(제거)할 때 즉시 영구 파기됩니다.
